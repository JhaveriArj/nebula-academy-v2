# Privacy, for parents and mentors

> **Draft.** This page has not been checked by a lawyer or a privacy expert. It needs review by
> a person qualified to review it before anyone relies on it.

## The short version

Nebula Academy does not collect anything about you or your child. There is no account, no
sign-up, no email, no ads and no tracking. A child's work stays on the computer they use.

## What we collect

Nothing. We do not ask for a name, an email, an age or a school. We do not use cookies. We do
not use analytics. The site does not load anything from other companies: no ads, no fonts from
a font service, no social buttons and no tracking scripts. Every part of the site comes from
the site itself.

Like every website, the company that hosts the site (GitHub) sees the address of the computer
that asks for each page. We cannot see those records, and we do not keep them.

## What is stored on this device

Lesson progress is saved in the web browser on the computer being used. This is called local
storage. It holds:

- which lessons are passed, and when;
- the code written in each lesson;
- display choices, such as Explorer or Builder mode and text size.

This never leaves the computer unless you choose to save it to a file. The file is yours: you
can keep it, move it to another computer, or delete it.

One thing to know: the site's address is shared with the owner's other GitHub Pages projects
(everything under the same github.io name). Browsers keep local storage per address, so those
other projects could in principle read what this site saves, and this site could read theirs.
Nebula Academy reads only its own two entries and stores nothing sensitive in them, only lesson
progress, code and settings, and a class membership key if a child has joined a class.

## The one exception: class codes

A mentor can make a class and give out a class code. If a child joins a class, the site sends
three things to our class server, which is run by a company called Supabase in the United
States:

- the class code;
- a nickname the child types (we ask for a first name or a made-up name, never a full name);
- which lessons they pass, and when.

Their code, their real name and everything else stay on the computer. The mentor can see the
nicknames and passed lessons in their class. A child can leave the class at any time, and that
deletes their nickname and passes from the server. A mentor can delete the whole class, which
deletes everything in it.

If nobody uses a class code, nothing is sent to the class server at all.

Before using class codes with children under 13, please check with your school or team about
asking parents first.

## How to clear everything

- **On the Progress page,** you can save a copy of the progress first if you want to keep it.
- **To delete it,** press "Clear everything" on the Progress page. That removes the passed
  lessons and saved code from this browser, and nothing else. (Clearing the site's data in the
  browser's settings also works, but it would clear the owner's other github.io projects too.)
- **To leave a class,** open the Progress page and press "Leave the class" first, so the nickname
  and passes are deleted from the server too.
